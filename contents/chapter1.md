# 第一章 我黄族概考

## 一、粤东迁竹邑南路高穴场

我族为黄峭山郑夫人第六子（峭山公第二十子）黄井之后裔。

祖先从湖北荆州——孝感乡——福建邵武市（唐末公元872—953年峭山公最为繁昌时期）——莆田县——梅州市——江西信丰县谭庆堡古城苦株树。明朝正统三年（戊午1438年），族系迁居湖南省宜章永平乡中堂里村分族系。由举人推官，时任广东韶州府训导的黄克忠之子黄荣率族人居广东省韶州府乐昌县上富村。黄荣并编排辈序：

| 后又二十辈:      |                    |   
| :------------- | :----------------- |
| 升海永俞玉，     | 大明国政端。          |
| 昌显光宏毅，     | 中和赞（占）化（香）宽。|
| 高登家贤仕，     | 名传启俊芳。          |
| 科文有平志（智），| 世代必兴隆。          |
| 叔浩克纯远，     | 此处行胜崇。          |

黄国胜为黄明用长子，为官为商常往来于广东、福建、江西，清朝顺治初年（1644年）病逝江西籍（现湖南宜章市）。国胜夫人吴氏率子政选等人迁居宜章永平乡中堂里村数年转乐昌县上富村本地几载，顺治年间（1644——1661）应时策而商议族友入川。吴氏始祖母念夫君国胜需后祭祀，聚族亲娘母商筹捡筯骨持家谱同行入川，竹邑南路高穴场——大竹县长乐乡长春里佑五甲黄家沟皇竹坳数载，清雍正初年（1723年）新修黄家老屋（高穴镇长远村8组），相继修新屋基（荣华8组），买新屋嘴（荣华8组），板桥场（金鸡乡东风桥一带），锣鼓洞（金鸡乡刘家村一、二组），杨子坝（长远村杨子坝），插蜡坝（高穴镇丁字桥一带，原属五仓乡）田地房产。

千里负检筋骨携五子徙迁入川蜀，大凡不亏伟业之奇，孺人吴氏始祖母也；佐母之奇男子黄政选字孝先也。

后又统一四川省大竹县高穴镇荣华黄氏祠堂辈序（注一）

| 升海永俞玉，| 大明国政端。|
| :-------- | :-------- |
| 昌显光宏毅，| 中和赞化宽。|
| 高登嘉贤仕，| 奉传启俊芳。（注二）|
| 科文有锦瑞，| 紫阳必兴隆。|
| 叔浩克纯远，| 泽德先胜崇。（注三）|
| 千秋之伟业，| 繁荣继纲常。（注四）|

> 注一：另庙坝镇老场村8组板板桥、高穴镇大山村黄氏清明会同此辈序。
> 
> 注二：上川时（1690年）只有“升”到“芳”30辈。“赞”字辈可用“占”；“化”字辈可用“香”或“志”。原“明”与“名”同音，“名”更为“奉”。
> 
> 注三：“科”到“崇”20辈是1926年在高穴场东粤宫由上川人黄国胜（高穴镇荣华村清明会）、黄国傚（庙坝镇板板桥清明会）、黄国亨（上川时在姚市乡楼房村一组黄家湾，现在高穴镇大山村清明会）后裔联命派的20辈。
> 
> 注四：“千”到“常”10辈是丁亥年2007年6月24日黄中礼、黄毅合（国傚后裔）在妈妈镇黄占明办公室三人商定命派的10辈。

## 二、建清明会祠堂

政选公，祖妣张氏二老先年所立丞尝（注①）会清明沟田地、房屋、山场、租谷二十担有余，又新买板桥场（现金鸡乡东风桥一带）。新屋嘴（现荣华8组）田地、房屋的租谷三十担有余，以作每年祭祀之费，祖有恩孙有德，尊祖敬祖宗为念，既立祭田以垂久远源远流长，后世积多余金，子孙松柏枝茂而笃（注②）亲亲之大义，各族轮流经费无容推迟，虽（注③）历千万世子孙是有荣矣。

嘉庆丙辰年（公元1796年）间，遵政选公嘱，老倡之幼者和之，相兴祖业清明沟建清明会祠堂（长远村8组）。清明会存留六十担租谷的田地、山林、房屋永作春秋之祀纵，建学堂育子孙，攒钱谷扶贫弱。既立申明家训：“初命曰：洁粢盛敬先灵，非铺啜贪饮。再命曰：内尽诚外，尽礼门内，和而家道成。三命曰：有无共患难同，父慈子孝，兄友弟恭。四命曰：急去逆当，效毋以小利而害义，莫因争端而失伦。五命曰：勿逞富、勿欺贪，尊卑长幼当有序，仁义礼智宜奉行……”逐年人丁繁多昌盛，清明会规定以“光”字辈起的后裔行成小清明会祭祀祖宗，登订人丁。每年清明节聚会铁厂沟清明会祠堂，施拜祀祖，记丁续谱，交际族谊，授训族规，惩戒不法不规者，济贫扶弱，分享祠堂谷币 … …

> 注①：丞尝：丞（文）众多之意，尝：曾经之意。这里指多次说。
> 
> 注②：笃du忠实，全心全意。
> 
> 注③：既使，纵使之意。

## 三、赞入川始祖黄母吴氏

黄国胜公为官为商常年往返于广东、福建、江西，清朝顺治初年（公元1644年）病逝江西籍，夫人吴氏率子从粤东韶州府乐昌县上富村狮子岭移居宜章永平乡中堂里村居住数载，转回广东韶州府乐昌县原籍居住数所，应时策而商议族亲朋友入川。吴氏祖母念夫君，聚族亲娘母商筹弃房产家业，捡夫君筋骨移居入川。居竹邑南路高穴场黄家沟皇竹坳（大竹县长乐乡长春里佑五甲，现大竹县高穴镇荣华村8组铁坳子外长远村8组湾里）居住。

后人赞颂吴氏曰：大凡不亏之事业人，唯独出于奇男子，吾谓亦出于奇妇黄母吴孺人则有然矣。吴母孺人有诸葛之谋略，储太君之雄识。具观音之慧心，举家人数千里徙迂，历严冬酷署，涉万水千山，辞千辛万苦，真圣贤女杰也。又有诗颂吴氏始祖母贞节曰：吴公之女，出竹之阳，性秉坤顺，志通乾刚，事业尽道，相夫有光，胜公谢世，节比共疆，心同金石，气若冰霜，遗腹生子，礼祀丞尝，孺人抚育，教育义方，携持抢保，终焉久臧（注①），享寿六九，四世同堂，音容虽杳，懿德孔长，兰枝业起，继序其皇（注②），他年修史，珍重勿忘。

> 注①：终焉久臧。终：终身之意。焉：之（这），于此（在这）之意。臧：（丈）善、好。全句子是指：吴氏祖母终身都具备有善良、美好的品性。
> 
> 注②：兰枝业起，继序其皇。兰：古书上指栏（一种乔木）。业：事业。继：接续，随后。皇（文）大、盛。此全句意思为：人丁繁衍，事业藩昌，撰书续谱，都要把吴氏祖母写在首要位置。

## 四、颂上川祖黄政选

上川祖黄政选公，入川始祖母吴氏长子，生于××××年五月初四日。政选公身魁气轩，文韬武略，志邃谟远（注①），敬宗孝祖，夫妇敬如嘉宾，兄弟情同手足。辅佐母亲粤南入川蜀创业，兴家业年绵耕丰，育子孙弟勤读圣贤。老谱书颂曰：祖之为人，正直聪明。事亲事长，克俭克勤。言遵古训，行依先民。无乖无忤（注②），有典有型。惜天不祚（注③），弱冠（注④）修文，明用之后（注⑤），幸有达人，丕承厥志（注⑥），大振家声，绳其祖武，贻厥子孙（注⑦），七十余逝，应亦忻心（注⑧），挥毫纪绩，奕世永存（注⑨）。

> 注①：志邃谟远。邃（音岁）〈文〉深远。谟：策略、计划。志向深远，策略精深。
> 
> 注②：无乖无忤。乖〈文〉违背、抵触。忤〈文〉违逆、抵触。意思为：与意愿无违背，与人无违逆。
> 
> 注③：惜天不祚。祚（音坐）〈文〉①福；②古代指皇位。本意为老天没有赋予为官为宦。
> 
> 注④：弱冠〈文〉少年。
> 
> 注⑤：明用之后。指黄政选的祖父黄明用。
> 
> 注⑥：丕承厥志。丕〈文〉大，例：丕业。厥〈文〉其、他的。
> 
> 注⑦：贻〈文〉①赠送；②遗留。
> 
> 注⑧：忻（音新）。①姓；②同“欣”。意即：欢喜、高兴。
> 
> 注⑨：奕〈文〉①大；②美。
